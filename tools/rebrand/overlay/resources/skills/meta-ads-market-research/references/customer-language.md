# Step 2 - Customer Language Bank

Purpose: turn the real words the user sends into a bank you can write ads from. The user collects; you
organize. Use only what they sent.

## What to ask for (tell the user this)

> "I-send mo sa'kin ang mga totoong sinasabi ng customers. Pwedeng copy-paste o screenshot:"
> - Reviews (Shopee, Lazada, TikTok Shop, Google Maps, FB page reviews) - pati 3-star at 1-star
> - Comments sa posts at ads (sa page mo at sa competitors)
> - DMs / inbox - lalo na mga tanong bago bumili at mga dahilan kung bakit hindi tumuloy
> - Sagot sa polls, surveys, o kung ano sinabi nila nang personal
> - Optional: posts sa FB groups o Reddit tungkol sa problema
> "Mas marami, mas maganda - pero kahit 15-20 okay na para magsimula."

If they send screenshots, read the text from them. Keep the source of each quote (e.g. "Shopee review",
"FB comment", "DM").

## Output: Customer Language Bank

### 1. Quick inventory
One line: how many data points, from which sources. Flag what's missing (e.g. "walang DMs - dito madalas
ang objections").

### 2. The Bank (the main table)

| Category | What they say (verbatim) | Source | How often |
|---|---|---|---|
| **Pain / problem** | | | |
| **Want / desire** | | | |
| **Hate / frustration** (sa category o sa ibang brand) | | | |
| **Objection / hesitation** | | | |
| **Buying trigger** (bakit bumili) | | | |
| **Result / after** (ano nangyari pagkatapos) | | | |
| **Price / value** ("sulit", "mahal") | | | |

Group near-identical quotes and count them ("6 reviews"). Put the strongest, most specific quote first in
each group. A data point can sit in more than one category. If a category has nothing: "Wala sa data."

### 3. Their exact words
A short list of the **phrases and words customers actually use** that should go straight into ads (e.g.
"hindi na nagla-lagkit", "sulit sa presyo", "akala ko scam"). Also note words the business uses that
customers never say - avoid those in copy.

### 4. Assumption check (vs Phase 0)

| What the business assumed | What customers actually said | Verdict |
|---|---|---|
| | | ✅ Tama · ⚠️ May dagdag/iba nang kaunti · ❌ Mali · ❓ Walang data |

Keep to the 3-6 assumptions that matter most for ads (customer, main problem, main want, objections, why
they buy). The ❌ and ⚠️ rows are the gold - call them out in one sentence each.

### 5. Top 3 insights
Three short bullets: the strongest pain, the biggest objection to answer, and the best buying trigger -
each with one supporting quote. These lead Step 3.

Then ask what they want made (angles, hooks, scripts, ad copy).
