# Step 3 - Creatives (angles, hooks, scripts, ad copy)

Write only what the user asked for. Everything comes from the Customer Language Bank and the Phase 0
offer. Quote the customer's words; don't invent new "customer" lines.

Every ad has three jobs - check each creative against them:
1. **Mapansin** (thumb-stop) - people stop for relevance: start from one real situation.
2. **Maintindihan** - one main message per ad.
3. **Malinaw na next step** - the CTA says exactly what to do (and what to send in Messenger).

## Angles

Default 5 (or the number asked). Each angle is a different reason someone would buy.

| # | Angle | Built from (quote + source) | For who / what moment | Best format |
|---|---|---|---|---|

Mix the types: pain, desire/result, objection flip, buying trigger, comparison with the old way, identity
("para sa mga..."). Mark any angle that needs proof the business doesn't have: **proof needed: <type>**.

## Hooks

Default 10 (or the number asked), spread across the angles. Each hook = the first 3 seconds / first line.

| # | Hook (spoken / on-screen) | Angle | Pattern | Customer words used |
|---|---|---|---|---|

Patterns: call-out ("Para sa mga..."), pain question ending in 👀, specific scenario, quoted inner thought
("'Next month na lang.'"), result first, objection flip ("Akala ko scam din 'to..."), demonstration,
testimonial, comparison, new mechanism ("Hindi 'to X, 'to ay Y"). Reliable formula: **who it's for + the
benefit + a reason to keep watching**. Use the customer's exact phrases wherever possible.

## Scripts

Default 1-3 video scripts, 15-30 seconds, for the angles/hooks the user picked (if none picked, use the
strongest from the Top 3 insights). Format per script:

**Script <#> - <angle> · <length> · <style: UGC / founder / testimonial / demo>**

| Beat | Time | Spoken / voiceover | On-screen text | Visual / shot |
|---|---|---|---|---|
| Hook | 0-3s | | | |
| Agitate (pain, in their words) | 3-8s | | | |
| Reveal / how it works | 8-15s | | | |
| Proof | 15-22s | | | |
| CTA | 22-30s | | | |

Plus 3 alternative hooks for the same script. If the proof beat has no real proof yet, write the beat as a
placeholder and mark the script **NOT READY - kailangan ng <proof>**.

## Ad copy (when asked)

For static/image ads - 3 variants, each with a headline (≤ 40 chars) and CTA button:
- **Direct Offer** - offer + price/value + ✅ benefits + 👉 CTA
- **Pain Point** - situation → empathy → solution → proof → CTA
- **Short** - 1-3 lines + ✅ checklist + CTA
Plus 5 extra headlines. For video ads - 2 caption options: statement-led, and a Taglish question/quote hook.

Taglish style: conversational, short lines, emojis only where the brand uses them, the brand's term of
address for customers (Phase 0).

## Finish

Stop after delivering. One closing line offering more (another angle, turn a hook into a script, more
hooks). Don't add budget, testing or campaign plans unless asked.
